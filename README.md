
# PromptBeta ✳

A modern, responsive AI prompt library with category-based discovery, search, editable templates and one-click copying.

## Features

- 32 high-level prompt templates
- 13 prompt categories
- Search by title, category, description or prompt content
- Featured and alphabetical sorting
- Editable prompt modal
- One-click copy to clipboard
- Responsive design
- Built with vanilla HTML, CSS and JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.

For the best clipboard support, run the project using VS Code Live Server.

## GitHub Upload

```bash
git init
git add .
git commit -m "Build PromptBeta AI prompt library"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the username and repository placeholders with your GitHub details.

## Project Structure

- `index.html` — website structure
- `style.css` — layout and visual design
- `script.js` — prompts, search, filters, modal and copy functionality
